Startup effect (controller)

Plays when the controller powers up with the key. Random picks different colors each time; Mode 1 to 6 are fixed effects. After it plays, the lights go back to your saved look.

When I turn the lights on

Controller plays the startup effect above. Color chase and Fade in are run by the phone. All three finish on your saved look (color, effect and brightness).

Door warning

Warning

Flashes the lights as an alert. It needs the wireless door modules to be installed and paired.

LED strip setup (Factor)

Only change these if an effect looks wrong, like it stops early or runs the wrong way. Count is the number of LEDs (8 to 300). L and R set the side or direction. Changes send as soon as you leave the box.

Door modules

Pair the wireless door lights once in the GuanQi app under Drive, Add Sub Device. Pairing needs a Bluetooth scan that web pages can't do. After that, Celica Glow controls them with everything else.

Sync

Close the GuanQi app before connecting. The controller only accepts one phone at a time.
